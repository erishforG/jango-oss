# Jango 카피 톤앤매너 가이드

## 1) 브랜드 톤 원칙

### 명확함
- 한 문장에서 한 메시지 원칙을 지킵니다.
- 기능 설명보다 **사용자가 얻는 결과**를 먼저 말합니다.

### 신뢰
- 확인 가능한 사실 중심으로 작성합니다.
- 기대를 높이더라도 조건/범위를 숨기지 않습니다.

### 과장 금지
- 절대적 표현(예: "무조건", "완벽")을 피합니다.
- 경쟁 우위 암시는 가능하나, 단정적 우월 표현은 금지합니다.

## 2) 금지 표현
- 경쟁사 실명 언급 + 비교 문구
  - 예: "OOO보다 정확", "OOO에서 갈아타세요"
- 법적 리스크가 있는 우월/보장 표현
  - 예: "국내 1위", "수익 보장", "손실 0%"
- 오해를 유발하는 단정 문구
  - 예: "자동으로 모든 금융 데이터 연동"

## 3) 권장 표현
- 가치 중심: "무엇을 할 수 있는가"보다 "무엇이 달라지는가"
  - 예: "기록 시간을 줄이고 자산 흐름을 빠르게 파악"
- 행동 유도형: 다음 행동을 명확히 제시
  - 예: "우선 승인 신청", "같은 이메일로 다시 로그인해 주세요"
- 사용자 맥락 반영: 실패 시 대안/재시도 경로 제공
  - 예: "잠시 후 다시 신청해 주세요"

## 4) 로그인/베타 신청 마이크로카피 예시

### 로그인 페이지
- 헤드라인: `기록 시간은 줄이고, 자산 흐름은 더 선명하게.`
- 서브카피: `수입·지출만 기록하면 순자산 변화와 현금 흐름을 바로 확인할 수 있어요.`
- 보조 포인트: `CSV 가져오기 지원`

### 클로즈드 베타 안내
- 안내 배너: `현재 클로즈드 베타 운영 중입니다. 초대 또는 승인된 이메일로만 로그인할 수 있어요.`
- 신청 버튼: `우선 승인 신청`
- 신청 성공: `우선 승인 신청이 완료됐어요. 승인 소식을 이 이메일로 보내드릴게요.`
- 신청 실패: `신청 접수가 원활하지 않아요. 잠시 후 다시 신청해 주세요.`

## 5) PR 전 카피 QA 체크리스트
- [ ] 경쟁사 실명/직접 비교 문구가 없는가?
- [ ] 과장/우월/보장형 표현을 제거했는가?
- [ ] 기능 나열이 아닌 사용자 가치 중심으로 작성했는가?
- [ ] 실패/예외 상황에서 다음 행동 문구가 명확한가?
- [ ] 동일 상황 안내가 중복 노출되지 않는가?
- [ ] 핵심 버튼 라벨이 목적과 일치하는가? (예: 신청/로그인/재시도)

## 6) 리뷰 프로세스 (같이 점검)
1. 작성자: 위 체크리스트 셀프 점검
2. 리뷰어: 카피 톤 + 법적 리스크 항목 우선 확인
3. 머지 전: PR 템플릿 체크박스 전체 확인

> 운영 메모: 카피 수정 PR은 최소 1명 이상 리뷰를 권장합니다.
